0.11.02026-11-04Latest

The Miller attention gate

  • Attention audit — wave lint now hard-fails an issue past the ceiling: more than 7 Done-when items or cited files, more than 2 named ADR forks (Miller 1956, Cowan 2001; meta 5/5/1). 6–7 warns amber. The lint ceilings interpolate from the LIMITES constants, so the message can never drift from the gate.
  • Size: line carries the Miller: class beside the zone fit — prepare stamps it, amend recomputes it; the define process runs the audit before the plan directory is written.
  • Minors — zone_state exact integer math (exact for every zone, not just round ones), agents --line precedence note, the statusline README's render-cost clause naming every read, clamp-test teardown hygiene, stats wording dedup.
  • 547 tests, 116 guarantees (106 pinned).

0.10.02026-11-03

Smart zone + seat progress line

  • Smart zone — smart_zone config (default 100k): every issue gets a crude, documented context estimate; the Size: line states zone fit; dispatch warns loud when an implementer would drift out of the band. Warn, never refuse.
  • Seat progress line — wave agents --line for your statusline (one line, exit 0 always, zero gh), a chaining snippet that never replaces your own statusline, the seat table mandated in chat at every agent event, and spawns named wave-<N> so the host renders its native progress rows.
  • 529 tests, 115 guarantees (105 pinned), 11 mutation-checked guards.
